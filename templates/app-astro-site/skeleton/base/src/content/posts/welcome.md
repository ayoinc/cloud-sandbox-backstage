This site is built with [Astro](https://astro.build/). Every page is rendered
to HTML at build time, so it loads fast and can be hosted anywhere static files
can.

## What is here

- Posts written in Markdown, in `src/content/posts/`
- A list of posts, an RSS feed and a sitemap, all generated from those files
- Styles written with Tailwind CSS

Replace this post with your own, or read
[Writing content](../writing-content/) first.
